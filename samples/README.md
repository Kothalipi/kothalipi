# Samples

Put test recordings here (`.wav`). They are git-ignored by default so personal voices
are never committed by accident.

For the accuracy test set, record each sentence and save the expected text next to it:

```
samples/bn-001.wav   samples/bn-001.txt   # Bangla
samples/en-001.wav   samples/en-001.txt   # English
samples/mx-001.wav   samples/mx-001.txt   # mixed Bangla + English (code-switching)
```
