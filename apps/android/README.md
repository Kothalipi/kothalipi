# Kothalipi for Android

**Status:** Phase 4.

- **Language:** Kotlin
- **Form:** custom keyboard (`InputMethodService`) with a big mic button
- **Core:** `kothalipi-core` through UniFFI Kotlin bindings (JNI under the hood)
- **Models:** small quantized models only; download on first run instead of bundling
- **Bonus:** Bangla/English toggle right on the keyboard
